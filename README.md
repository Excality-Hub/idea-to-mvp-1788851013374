# App

Generated by idea-to-mvp. Run `npm install && npm start`.

## Todo List API

In-memory todo list. Data resets on server restart.

### `GET /todos`

Returns all todos in creation order.

```
200 OK
[
  { "id": 1, "title": "buy milk", "done": false }
]
```

### `POST /todos`

Creates a todo. `title` must be a non-empty string.

Request:

```
POST /todos
{ "title": "buy milk" }
```

Response:

```
201 Created
{ "id": 1, "title": "buy milk", "done": false }
```

If `title` is missing or empty:

```
400 Bad Request
{ "error": "title is required" }
```

### `POST /todos/:id/done`

Marks a todo as done.

Response:

```
200 OK
{ "id": 1, "title": "buy milk", "done": true }
```

If no todo exists with that id:

```
404 Not Found
{ "error": "todo not found" }
```
